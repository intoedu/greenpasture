# 문의 · 신청서 받기 설정 (구글 시트 · 이메일 · 전화 · 문자 · 카카오톡)

홈페이지는 **서버 · 데이터베이스 없이** 방문자 연락을 받습니다. 연결 경로는 네 가지입니다.

| 경로 | 동작 | 설정 |
|---|---|---|
| **문의 · 신청 양식** | 구글 시트에 기록하고 회사 이메일로 알림 (또는 Web3Forms 로 이메일 전달) | 아래 1장 또는 2장 — 둘 중 하나 |
| **전화 버튼** | 누르면 바로 전화 연결 (`tel:+821034972524`) | 설정 없음 |
| **문자 버튼** | 누르면 문의 문구가 채워진 문자 창이 열림 (휴대폰에서만 표시) | 설정 없음. 문구는 `assets/js/site.js` 의 `SITE.smsKo` · `smsEn` |
| **카카오톡 상담 버튼** | 카카오톡 채널 1:1 채팅으로 연결 | 아래 3장 — 채널 주소 한 줄 |

> 양식 설정을 아직 안 했어도 신청서는 받을 수 있습니다.
> 그동안은 방문자의 **메일 앱**이 열려 `ceo@greenpasture.co.kr` 로 보내도록 안내합니다.
> (메일 앱이 없는 방문자를 위해 "내용 복사" 버튼과 전화번호도 함께 보여 줍니다.)

하루 알림 한도를 넘으면 그날 초과분은 **시트에만 기록**되고 메일은 오지 않습니다.

## 1. 구글 시트 방식 (권장)

**고객사 구글 계정**으로 진행하는 것이 좋습니다. 기록이 고객사 소유가 되고, 제작사가 손님 개인정보를 보관하지 않게 됩니다.

1. 구글 드라이브 → **새로 만들기 → 구글 스프레드시트** (이름 예: `그린파스처 홈페이지 신청서`)
2. 시트 메뉴 **확장 프로그램 → Apps Script**
3. 편집기에 있던 내용을 지우고, 저장소의 [`tools/apps-script/Code.gs`](../tools/apps-script/Code.gs) 내용을 **전부 붙여넣기**
4. 맨 위 `RECEIVER` 를 신청서를 받을 이메일로 확인 · 수정 (여러 명이면 쉼표로 구분) → **저장**
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 설명: `홈페이지 신청서`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포** → 권한 검토 → 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동** → 허용
     (직접 만든 스크립트라서 나오는 정상 안내입니다)
7. 표시되는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사
8. 홈페이지 `assets/js/config.js` 의 `APPS_SCRIPT_URL: ''` 따옴표 안에 붙여넣기 → 저장 → 배포

시트에는 `신청서` 탭이 자동으로 생기고, 접수 일시 · 제목 · 신청 내용 · 문의 내용 · **처리 상태** · **메모** 칸이 있습니다.
처리 상태와 메모는 담당자가 직접 적어 가며 관리하시면 됩니다.

**코드를 고친 뒤에는** 배포 → 배포 관리 → ✏️ → 버전: **새 버전** → 배포 를 해야 반영됩니다. (주소는 그대로)

### 스팸 · 반복 전송
- 사람에게는 보이지 않는 칸(허니팟)에 값이 들어온 신청은 조용히 버립니다.
- 같은 이메일 주소로 10분 안에 5번이 넘으면 막습니다. (`Code.gs` 의 `MAX_PER_10MIN`)
- 시트에 `=` · `+` · `-` · `@` 로 시작하는 값은 앞에 `'` 를 붙여 수식으로 실행되지 않게 합니다.

## 2. Web3Forms 방식 (가장 간단)

1. https://web3forms.com 접속 → **Create your Access Key** 에 신청서를 받을 이메일(`ceo@greenpasture.co.kr`) 입력
2. 그 메일함에 온 **Access Key** 복사
3. `assets/js/config.js` 의 `WEB3FORMS_ACCESS_KEY: ''` 따옴표 안에 붙여넣기 → 저장 → 배포

> Access Key 는 공개돼도 되는 값입니다 (받는 주소는 Web3Forms 쪽에 묶여 있어 바꿀 수 없음).
> 받은 메일에서 **답장**을 누르면 신청자에게 바로 갑니다.

구글 시트 주소와 Web3Forms 키가 **둘 다** 있으면 구글 시트가 우선입니다. 특정 방식만 쓰려면 `EMAIL_SERVICE` 를 `'apps-script'` 또는 `'web3forms'` 로 적으십시오.

## 3. 카카오톡 상담 버튼

1. [카카오톡 채널 관리자센터](https://center-pf.kakao.com) 에서 고객사 채널 개설 (무료)
2. 채널 설정에서 **1:1 채팅 사용**을 켜고, 채널 홈 주소 확인 (예: `https://pf.kakao.com/_AbCdE`)
3. `assets/js/site.js` 의 `SITE` 에 입력
   ```js
   kakaoChat: 'https://pf.kakao.com/_AbCdE/chat',   // 상담 버튼 (모바일 메뉴 · 떠 있는 버튼)
   sns: { kakao: 'https://pf.kakao.com/_AbCdE', … }  // 푸터 SNS 아이콘
   ```
   대표님 개인 번호를 드러내지 않고 상담을 받을 수 있고, 대화 기록은 채널 관리자센터에 남습니다.

## 4. 설정 후 점검 (공개 전 반드시)

- [ ] `contact.html` 에서 한국어로 문의 1건 → 알림 메일 도착 · (구글 시트면) 시트에 한 줄 추가
- [ ] `apply.html?type=visit&lang=en` 에서 영어로 방문 예약 1건 → 메일 제목 `[홈페이지 시공 상담 · 방문 예약] …`
- [ ] 받은 메일에서 **답장** → 받는 사람이 신청자 이메일인지
- [ ] 메일이 스팸함에 가지 않았는지 (갔다면 "스팸 아님" 처리)
- [ ] 휴대폰에서 전화 · 문자 버튼 동작, 문자에 문의 문구가 채워지는지
- [ ] 개인정보처리방침(`privacy.html`)의 처리 위탁 · 국외 이전 항목이 **실제로 쓰는 방식**과 맞는지

## 5. 자주 생기는 문제

| 증상 | 원인 · 해결 |
|---|---|
| 신청하면 메일 앱이 열린다 | `config.js` 에 주소 · 키가 비어 있음. 1장 또는 2장 진행 |
| "이메일로 보내지 못했습니다" 안내가 뜬다 | 구글 시트: 배포 액세스 권한이 "모든 사용자"인지, 주소가 `/exec` 로 끝나는지. Web3Forms: 키 오타. 이때도 방문자에게는 "메일 앱으로 보내기" 버튼이 함께 나와 신청이 끊기지 않습니다 |
| 시트에는 쌓이는데 메일이 안 온다 | 하루 알림 한도 초과 또는 스팸함. `RECEIVER` 주소 확인 |
| 코드를 고쳤는데 그대로다 | Apps Script 는 "새 버전"으로 다시 배포해야 반영 |
| 홈페이지를 고쳤는데 그대로다 | 브라우저 캐시. HTML 의 `?v=` 번호를 올려 배포 |
