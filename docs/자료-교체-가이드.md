# 자료 교체 가이드 — 새 자료가 오면 바로 바꾸기

고객사에서 자료가 오면 이 표에서 해당 줄을 찾아 **그 파일만** 고치면 됩니다.
사진 · 로고는 `tools/images.py` 로 웹용 파일을 만든 뒤 **같은 이름으로 덮어쓰면** HTML 은 고칠 필요가 없습니다.
(도구 사용법: [`tools/README.md`](../tools/README.md))

확인이 끝난 항목은 해당 요소의 `data-tbd` 속성과 `tbd-only` 클래스를 지우고,
[`docs/고객-확인사항.md`](고객-확인사항.md) 의 체크박스를 채우십시오.
남은 항목은 주소 뒤에 `?review` 를 붙여 열면 노란 점선으로 보입니다.

## 4. 바꾼 뒤에

1. 로컬에서 확인: `python3 -m http.server 8080` → `http://localhost:8080/` (영문은 `?lang=en`)
2. CSS · JS 를 고쳤다면 모든 HTML 의 `?v=` 번호를 하나 올림 (브라우저 캐시 갱신)
3. `main` 에 반영하면 1~2분 뒤 자동 배포
