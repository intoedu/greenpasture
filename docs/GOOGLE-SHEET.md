# 구글 시트로 문의 · 신청 받기 — 설치 안내

홈페이지의 **문의하기 · 신청(견적 · 샘플 · 방문 예약 · 파트너 · 자료 요청)** 양식을
구글 시트에 한 줄씩 쌓고, 새 접수가 들어오면 담당자에게 알림 메일을 보내는 방법입니다.

처음 한 번만 하면 되고, 15~20분 정도 걸립니다. 비용은 들지 않습니다.

## 지금 상태

| | 할 일 | 누가 |
|---|---|---|
| ✅ | 연결 코드 작성 (`google-sheet/Code.gs`) | 완료 |
| ✅ | 홈페이지 양식이 시트로 보내도록 수정 (`assets/js/form.js`) | 완료 |
| ✅ | 개인정보처리방침 위탁 · 국외 이전 항목을 구글 기준으로 수정 (`privacy.html`) | 완료 — 고객사 확인 필요 |
| ⬜ | 1~5번: 시트 만들기 · 코드 붙여 넣기 · 배포 | 담당자 (아래 순서대로) |
| ⬜ | 6번: 배포 주소를 `assets/js/config.js` 의 `SHEET_URL` 에 넣기 | 주소만 전달해 주시면 제작사가 반영 |
| ⬜ | 7번: 전 구간 시험 | 함께 |

`SHEET_URL` 이 비어 있는 동안에는 **지금처럼 방문자의 메일 앱을 여는 방식**으로 동작합니다. 홈페이지가 멈추지 않습니다.

---

## 0. 전체 구조

```
 방문자 ─▶ 홈페이지 양식 ─▶ 구글 Apps Script(접수 주소) ─▶ 구글 시트 "접수" 탭에 한 줄 저장
                              · 값 · 동의 다시 검사                │
                              · 자동 입력 프로그램 차단            ▼
                              · 같은 사람 60초 안 재접수 차단   담당자 알림 메일
                              · 10분에 30건 넘으면 잠시 차단   (하루 한도 안에서만, 넘으면 건너뜀)
                                                              (선택) 텔레그램 알림
```

- **저장이 먼저, 알림은 나중입니다.** 메일 한도를 넘거나 메일이 실패해도 접수는 시트에 남습니다.
  시트 맨 오른쪽 **"알림 발송"** 칸에 메일이 갔는지 적힙니다.
- 서버 연결에 문제가 생기면 방문자 화면에 **"작성한 내용을 메일로 보내기"** 버튼이 나타나, 작성한 내용을 잃지 않습니다.

## 1. 어느 구글 계정으로 만들지 정하기 (중요)

**시트를 만들고 코드를 배포하는 계정이 곧 "주인"이자 "알림 메일을 보내는 주소"가 됩니다.**

- **회사 계정 `info@intomarketing.co.kr` 로 로그인해서 만드시는 것을 권합니다.**
  개인 계정으로 만들면, 그 사람이 팀을 떠나거나 계정을 정리할 때 시트와 연결이 함께 사라질 수 있습니다.
- `intomarketing.co.kr` 의 메일 서버는 구글로 되어 있어, 이 주소가 **구글 워크스페이스 계정일 가능성이 높습니다.**
  워크스페이스 계정이면 알림 메일 한도가 **하루 1,500명**, 일반 gmail 계정이면 **하루 100명**입니다.
  (이 주소가 실제 로그인 계정인지, 다른 계정으로 전달만 되는 별칭인지는 확인하지 못했습니다.
  구글 로그인이 되면 계정이 맞습니다.)

## 2. 빈 시트 만들기 (1분)

1. `info@intomarketing.co.kr` 로 로그인한 상태에서 주소창에 **`sheets.new`** 를 입력하면 빈 시트가 열립니다.
2. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 **`그린파스처 홈페이지 접수`** 로 바꿉니다.
3. **아무것도 적지 않아도 됩니다.** 머리글 · 색 · 칸 너비 · 처리상태 목록은 4번에서 자동으로 만들어집니다.

## 3. 연결 코드 붙여 넣기 (2분)

1. 시트 메뉴 **[확장 프로그램] → [Apps Script]** 를 누릅니다. 새 탭이 열립니다.
2. 왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 **`그린파스처 접수 연결`** 로 바꿉니다.
3. 가운데 편집 창의 `function myFunction() { }` 을 **모두 지우고**,
   이 저장소의 **`google-sheet/Code.gs` 내용 전체**를 붙여 넣습니다.
4. 알림 받을 메일을 확인합니다. 코드 위쪽 `NOTIFY_EMAILS` 에 `info@intomarketing.co.kr` 이 들어 있습니다.
   고객사(그린파스처)도 함께 받으려면 `['info@intomarketing.co.kr', 'ceo@greenpasture.co.kr']` 처럼 추가합니다.
   **받는 사람 1명당 하루 한도 1건을 씁니다.**
5. **저장**(디스크 모양 아이콘 또는 Ctrl + S)을 누릅니다.

## 4. 시트 모양 만들기 + 권한 허용 (3분)

1. 편집 창 위쪽의 함수 선택 칸에서 **`setup`** 을 고르고 **[실행]** 을 누릅니다.
2. "승인 필요" 창이 뜨면 **[권한 검토]** → 계정 선택.
3. **"Google에서 확인하지 않은 앱"** 경고가 나옵니다. 내가 직접 붙여 넣은 코드라서 뜨는 정상 화면입니다.
   왼쪽 아래 **[고급]** → **[그린파스처 접수 연결(으)로 이동(안전하지 않음)]** → **[허용]**.
   > ⚠️ 남이 보내 준 코드를 붙여 넣은 경우라면, 이 단계에서 반드시 코드 내용을 먼저 확인하십시오.
   > 이 권한은 "이 시트 수정 · 메일 보내기 · 외부 주소 호출(텔레그램 · 캡차용)"입니다.
4. 아래 "실행 로그"에 **`시트 준비 완료`** 가 보이면 성공입니다. 시트로 돌아가면 **"접수"** 탭에 머리글이 생겨 있습니다.
5. (권장) 함수 선택 칸에서 **`testNotify`** 를 골라 **[실행]** → `info@intomarketing.co.kr` 로 **[시험] 메일**이 오는지 확인합니다.

## 5. 웹 앱으로 배포하기 (3분)

1. 오른쪽 위 **[배포] → [새 배포]**.
2. "유형 선택" 옆 **톱니바퀴** → **[웹 앱]**.
3. 아래처럼 고릅니다.

   | 칸 | 값 |
   |---|---|
   | 설명 | `홈페이지 접수` |
   | 다음 사용자 인증 정보로 실행 | **나** (`info@intomarketing.co.kr`) |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   > "모든 사용자"는 **누구나 접수를 "보낼" 수 있다**는 뜻입니다. 시트를 "볼" 수 있다는 뜻이 아닙니다.
   > 홈페이지 방문자는 로그인하지 않으므로 이렇게 해야 접수가 됩니다. 시트는 공유한 사람만 볼 수 있습니다.

4. **[배포]** → **웹 앱 URL** (`https://script.google.com/macros/s/……/exec`) 을 **복사**합니다.
5. 복사한 주소를 새 탭에서 열어 보십시오.
   **"그린파스처 홈페이지 접수 연결이 정상입니다."** 가 보이면 성공입니다.

(화면의 버튼 이름은 구글이 바꿀 수 있어 조금 다를 수 있습니다.)

## 6. 홈페이지에 주소 넣기

`assets/js/config.js` 의 `SHEET_URL` 에 5번 주소를 넣고 `main` 에 올리면 1~2분 뒤 홈페이지에 반영됩니다.

```js
SHEET_URL: "https://script.google.com/macros/s/……/exec",
```

**주소만 제작사에 전달해 주시면 반영해 드립니다.**
이 주소는 홈페이지 코드에 그대로 보이는 "공개 값"이라 저장소에 올라가도 괜찮습니다.

## 7. 전 구간 시험

| # | 해 볼 것 | 기대 결과 |
|---|---|---|
| 1 | `apply.html` 에서 "견적 요청"으로 시험 접수 | 완료 화면 · 시트에 한 줄(노란색 "신규") · 알림 메일 |
| 2 | `contact.html` 에서 문의 접수 | 같음 |
| 3 | 연락처를 `01012345678` (숫자만)로 접수 | 시트에 **앞자리 0 이 그대로** 보임 |
| 4 | 1번을 60초 안에 같은 연락처로 한 번 더 | "짧은 시간에 여러 번 접수하셨습니다" 안내, 시트에 안 쌓임 |
| 5 | 영문 화면(`apply.html?lang=en`)에서 접수 | 시트 "작성 언어"가 영어 |
| 6 | 메일 답장 | 신청자 메일 주소로 답장됨 |

시험한 줄은 확인 후 지워 주십시오.

## 8. 평소 쓰는 법

- **처리상태**: 신규 → 확인 → 상담 중 → 견적·샘플 발송 → 완료 / 보류 (칸을 누르면 목록이 나옵니다).
  "신규"인 줄만 노란색입니다. 상태를 바꾸면 색이 빠져, 남은 일이 한눈에 보입니다.
- **담당자 메모**에 통화 내용 · 다음 할 일을 적습니다.
- **정렬 · 필터**: 머리글 줄을 누르고 [데이터] → [필터 만들기].
- **엑셀로 받기**: [파일] → [다운로드] → Microsoft Excel. 받은 파일은 개인정보이니 다 쓰면 지워 주십시오.

## 9. 공유 · 보안 (꼭 지켜 주십시오)

- **"링크가 있는 모든 사용자"로 공유하지 마십시오.** 신청자 이름 · 연락처 · 이메일이 들어 있습니다.
  오른쪽 위 **[공유]** 에서 **담당자 이메일만** 추가합니다. 처리상태를 바꿀 사람은 "편집자", 보기만 할 사람은 "뷰어".
- 담당자가 바뀌면 공유 목록에서 바로 빼 주십시오.
- 시트의 [파일] → [버전 기록]에서 누가 언제 무엇을 고쳤는지 볼 수 있습니다.
- 알림 메일에도 개인정보가 들어 있습니다. 다른 사람에게 전달하지 마십시오.

## 10. 한도 (2026년 9월 확인, 구글이 바꿀 수 있음)

| 항목 | 일반 gmail 계정 | 구글 워크스페이스 계정 |
|---|---|---|
| 알림 메일 (받는 사람 수 기준) | 하루 100명 | 하루 1,500명 |
| 외부 주소 호출 (텔레그램 · 캡차) | 하루 20,000회 | 하루 100,000회 |
| 시트 저장 | 사실상 제한 없음 (한 시트 최대 1,000만 칸) | 같음 |

메일 한도를 넘으면 **메일만 건너뛰고 저장은 계속됩니다.** "알림 발송" 칸에 "메일 한도 초과로 안 보냄"이 적힙니다.
한도는 첫 발송 후 24시간이 지나면 다시 채워집니다.

한 줄에 칸이 23개라, 한 시트에 약 40만 건까지 쌓을 수 있습니다.

## 11. 선택 기능

### 텔레그램 알림 (무료, 한도 사실상 없음)
1. 텔레그램에서 `@BotFather` → `/newbot` → 봇 이름 정하기 → **토큰**을 받습니다.
2. 만든 봇과 대화를 시작해 아무 말이나 보낸 뒤,
   브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열어 `"chat":{"id": 숫자}` 의 **숫자**를 찾습니다.
3. Apps Script 왼쪽 **톱니바퀴(프로젝트 설정)** → 맨 아래 **[스크립트 속성 추가]**
   - `TELEGRAM_BOT_TOKEN` = 토큰
   - `TELEGRAM_CHAT_ID` = 숫자
4. `testNotify` 를 실행해 텔레그램으로 [시험] 알림이 오는지 확인합니다.

텔레그램 알림에는 **구분 · 회사명 · 접수번호만** 들어가고, 성함 · 연락처는 넣지 않습니다.
토큰은 코드에 적지 마십시오. 코드에 적으면 코드를 보는 누구나 봇을 쓸 수 있습니다.

### 캡차 (스팸이 많아지면)
1. Cloudflare 에서 Turnstile 위젯을 만들고 **사이트 키**와 **비밀 키**를 받습니다. 허용 도메인에 홈페이지 주소를 넣습니다.
2. 사이트 키 → `assets/js/config.js` 의 `TURNSTILE_SITE_KEY`
3. 비밀 키 → Apps Script 스크립트 속성 `TURNSTILE_SECRET`

### 3년 지난 접수 자동 삭제
개인정보 동의서에 "처리 완료 후 3년 보관 후 파기"로 안내하고 있습니다.
Apps Script 왼쪽 **시계(트리거)** → **[트리거 추가]** → 함수 `deleteExpired` · 이벤트 소스 "시간 기반" · "월 단위 타이머".
**접수일로부터 3년**이 지난 줄을 지웁니다. 지운 줄은 되돌릴 수 없습니다.

## 12. 코드를 고쳤을 때 (자주 하는 실수)

Apps Script 코드를 고쳐 저장만 하면 **홈페이지에는 반영되지 않습니다.**
**[배포] → [배포 관리] → 연필(수정) → 버전: "새 버전" → [배포]** 를 해야 합니다.
이렇게 하면 **주소는 그대로**라 홈페이지를 고칠 필요가 없습니다.
([새 배포]를 누르면 주소가 바뀝니다. 그 경우 `SHEET_URL` 도 바꿔야 합니다.)

## 13. 문제 해결

| 증상 | 원인 · 해결 |
|---|---|
| 제출하면 "접수되지 않았습니다 · 인터넷 연결을 확인" | 배포 "액세스 권한"이 **모든 사용자**가 아님 → 5번 다시. 또는 `SHEET_URL` 이 `/exec` 로 끝나는지 확인 (`/dev` 는 안 됨) |
| 접수는 되는데 메일이 안 옴 | 시트 "알림 발송" 칸 확인. "메일 한도 초과" → 다음 날 풀림. "메일 실패" → Apps Script [실행] 기록 확인. 스팸함도 확인 |
| 코드를 고쳤는데 그대로 | 12번 "새 버전" 배포를 안 함 |
| 시트에 "접수" 탭이 없음 | `setup` 을 한 번 더 실행 |
| 머리글 이름을 바꾸고 싶음 | 시트에서 직접 바꾸지 말고 `Code.gs` 의 `COLUMNS` 를 고친 뒤 `setup` 실행 · 새 버전 배포 |
| 권한 창에서 "이 앱은 차단됨" | 회사(워크스페이스) 관리 설정에서 Apps Script 가 막혀 있을 수 있음 → 관리자 콘솔 확인 |

## 14. 나중에 Supabase(관리자 페이지 방식)로 옮길 때

`assets/js/config.js` 의 `SUPABASE_URL` 을 채우면 그쪽이 우선합니다(`docs/SETUP.md`).
그때는 `privacy.html` 의 위탁 · 국외 이전 항목도 다시 바꿔야 합니다.
