# 주식회사 그린파스처 홈페이지

Green Pasture Co., Ltd. 공식 홈페이지 소스입니다. 나노 촉매 코팅 **V-ZERO**를 소개하고 견적 · 샘플 · 시공 상담 · 파트너 신청을 받습니다.

별도의 설치나 빌드 과정 없이 **HTML 파일을 그대로 열면 바로 동작**합니다. 서버 · 데이터베이스를 쓰지 않습니다.
메모장이나 VS Code 같은 편집기로 직접 수정하실 수 있습니다.

| `apply.html` | 신청 · 예약 | 견적 요청 / 샘플 신청 / 시공 상담 · 방문 예약 / 파트너 신청 / 자료 요청 (종류별로 입력칸이 바뀜) |
| `contact.html` | 문의하기 | 전화 · 문자 · 이메일 · 온라인 신청 카드, 문의 양식, 지도 |

영문 링크를 해외 거래처에 보낼 때 쓰십시오.

## 4. 자주 하는 수정 방법

### 연락처 · 사업자등록번호 · 응대 시간 · SNS · 카카오톡
`assets/js/site.js` 맨 위 **SITE** 부분만 고치면 헤더 · 푸터 · 모바일 메뉴 · 떠 있는 버튼에 **한 번에 반영**됩니다.
**비어 있는 칸은 공개 화면에 나오지 않습니다.** (검토 모드에서만 자리가 보임)

```js
const SITE = {
  tel: '010-3497-2524',
  telEn: '+82 10-3497-2524',
  telHref: '+821034972524',
  email: 'ceo@greenpasture.co.kr',
  smsKo: '[그린파스처 홈페이지 문의]\n성함:\n회사:\n문의 내용:',   // 문자 버튼 문구
  kakaoChat: '',        // ← 카카오톡 채널 1:1 채팅 주소를 넣으면 '카톡 상담' 버튼이 나타남
  hoursKo: '',          // ← 응대 시간
  bizNo: '',            // ← 사업자등록번호
  sns: { instagram: '', youtube: '', blog: '', facebook: '', linkedin: '', kakao: '' }
};
```

> 본문 몇 곳에도 전화번호 · 이메일이 직접 적혀 있습니다. 바뀌면 [자료 교체 가이드 1장](docs/자료-교체-가이드.md)대로 함께 바꾸십시오.

### 메뉴 추가 / 삭제 / 이름 변경
같은 파일의 **NAV_ITEMS** 배열을 수정합니다. `children` 은 드롭다운 하위 메뉴입니다.

### 글 내용 수정 (한글 / 영문)
본문은 한국어와 영어가 나란히 들어 있습니다. 필요한 쪽만 고치면 됩니다.

```html
<span data-lang="ko">한국어 문장</span>
<span data-lang="en">English sentence</span>
```

### 공지 · 소식 글 올리기
`assets/data/posts.js` 의 `GP_POSTS` 배열 **맨 위**에 아래 한 덩어리를 복사해 붙이고 내용만 바꿉니다.
저장하면 게시판과 메인 화면 "공지 · 소식"에 자동으로 나타납니다.

```js
{
  id: 'new-post-2026-11',          // 영문 · 숫자 · - 만 사용, 다른 글과 겹치지 않게
  category: 'news',                // notice 공지사항 / news 회사 소식 / tech 기술·자료 / press 보도자료
  date: '2026-11-01',
  pinned: false,                   // true 면 목록 맨 위 고정
  title:   { ko: '제목', en: 'Title' },
  summary: { ko: '한 줄 요약', en: 'One-line summary' },
  body: {
    ko: `<p>본문 문단</p>`,
    en: `<p>Body paragraph</p>`
  }
},
```

글 주소는 `news.html?id=글id` 입니다. 최근 14일 이내 글에는 NEW 표시가 붙습니다.

### 사진 · 로고 교체
`assets/img/` 에 **같은 이름으로 덮어쓰면** HTML 을 고칠 필요가 없습니다.
슬롯별 규격과 만드는 명령은 [자료 교체 가이드 2장](docs/자료-교체-가이드.md)에 있습니다.
로고를 바꾼 뒤에는 `python3 tools/images.py icons` 와 `node tools/make-og.js` 로 아이콘 · 공유 이미지도 다시 만드십시오.

> 현재 이미지는 고객사가 보내 준 **V-ZERO 리플릿(인쇄용 PDF)에서 잘라낸 것**입니다. 원본을 받으면 교체하십시오.

### 색상 바꾸기
`assets/css/style.css` 맨 위 `:root { ... }` 안의 색상 값만 바꾸면 사이트 전체 톤이 바뀝니다.

### CSS · JS 를 고친 뒤
각 HTML 의 `style.css?v=2` 처럼 붙은 번호를 하나 올리십시오. 방문자 브라우저가 옛 파일을 계속 쓰지 않게 합니다.

## 5. 검토 모드 — "확인이 필요한 곳" 한눈에 보기

주소 뒤에 **`?review`** 를 붙여 열면 (예: `index.html?review`)
고객 확인이 필요한 부분이 **노란 점선**으로 표시되고, 왼쪽 아래에 몇 개인지와 각 항목의 메모가 나옵니다.
"다음 항목 보기"를 누르면 차례로 이동합니다. 끄려면 `?review=0` 을 붙이거나 "검토 모드 끄기"를 누르십시오.

- `data-tbd="메모"` 가 붙은 곳이 확인 항목입니다.
- `class="tbd-only"` 는 **자료가 아직 없는 자리**(사업자번호 · 설립일 · 인증 등)로, 공개 화면에서는 숨고 검토 모드에서만 보입니다.
- **배포할 때 `data-tbd` 메모는 자동으로 지워집니다.** 고객과 배포 주소에서 검토 모드로 함께 보려면
  저장소 Settings → Secrets and variables → Actions → **Variables** 에 `KEEP_REVIEW_NOTES` = `true` 를 추가하고,
  검토가 끝나면 지우십시오.
- 오픈 전에는 모든 항목을 해결하는 것이 원칙입니다. 남은 항목: `grep -rn "data-tbd" --include=*.html --include=*.js .`

## 6. 방문자 연락 경로

| 경로 | 동작 |
|---|---|
| **전화** | 모든 페이지의 전화 버튼 · 번호를 누르면 바로 연결 (`tel:+821034972524`, 해외에서도 연결되는 형식) |
| **문자** | 휴대폰에서만 보이는 문자 버튼 — 문의 문구가 채워진 문자 창이 열림 (아이폰 · 안드로이드 형식 자동 구분) |
| **카카오톡** | `SITE.kakaoChat` 을 넣으면 모바일 메뉴 · 떠 있는 버튼에 '카톡 상담'이 나타남 |
| **문의 · 신청 양식** | `assets/js/config.js` 설정에 따라 **구글 시트 기록 + 이메일 알림** 또는 **Web3Forms 이메일 전달**. 설정 전에는 방문자의 메일 앱을 열어 보내게 함 |

설정 방법은 [docs/이메일-접수-설정.md](docs/이메일-접수-설정.md) 에 있습니다.
어느 방식이든 전송에 실패하면 방문자에게 **"메일 앱으로 보내기" 버튼과 전화번호**를 함께 보여 줘 신청이 끊기지 않게 했습니다.
양식에는 자동 입력 프로그램을 걸러내는 보이지 않는 칸(허니팟)과 개인정보 수집 · 이용 동의가 들어 있습니다.

## 7. 배포 및 도메인 연결

### 자동 배포
`main` 브랜치에 변경 사항이 올라가면 GitHub 가 1~2분 안에 홈페이지를 자동으로 갱신합니다.
설정은 `.github/workflows/deploy-pages.yml` 에 있으며, **홈페이지에 필요한 파일만** 올라갑니다
(`docs/`, `tools/`, `README.md`, `CLAUDE.md` 는 웹사이트에 올라가지 않습니다).

> ⚠️ 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 두십시오.
> "Deploy from a branch" 로 되어 있으면 저장소 전체(내부 문서 포함)가 그대로 공개됩니다.

- 기본 주소 : `https://intoedu.github.io/greenpasture/`
- 연결할 주소 : `https://www.greenpasture.co.kr`

### `www.greenpasture.co.kr` 연결 순서
1. GitHub 저장소 **Settings → Pages → Custom domain** 에 `www.greenpasture.co.kr` 입력 후 저장
   (자동 배포 방식에서는 `CNAME` 파일이 아니라 이 설정 화면이 기준입니다)
2. 도메인 등록 업체(가비아 · 후이즈 등) DNS 설정에 아래를 추가

   | 호스트 | 유형 | 값 |
   |---|---|---|
   | `www` | CNAME | `intoedu.github.io` |
   | `@` (루트) | A | `185.199.108.153` · `185.199.109.153` · `185.199.110.153` · `185.199.111.153` |

   값은 GitHub 공식 문서("Managing a custom domain for your GitHub Pages site")의 최신 값을 한 번 더 확인하십시오.
3. DNS 가 반영되면(수 분~최대 48시간) 같은 화면에서 **Enforce HTTPS** 를 켭니다.
4. 기존에 연결된 메일(MX 레코드)이 있다면 **메일 레코드는 건드리지 마십시오.** `ceo@greenpasture.co.kr` 수신이 끊길 수 있습니다.
5. `www.vzero.co.kr` 도 같은 사이트로 보내려면, 등록 업체의 "도메인 포워딩"으로 `https://www.greenpasture.co.kr/business.html` 로 넘기는 방법이 가장 간단합니다.

### 검색엔진 등록 (오픈 직후)
1. **네이버 서치어드바이저** (searchadvisor.naver.com) → 사이트 등록 → HTML 태그 방식의 확인 코드를
   `index.html` 의 `naver-site-verification` 주석 자리에 넣고 배포 → 소유 확인 → `sitemap.xml` 제출
2. **구글 서치 콘솔** 도 같은 방식 (`google-site-verification`)
3. `sitemap.xml` 의 `lastmod` 날짜는 큰 개편 때마다 갱신하십시오.

## 9. 알아두실 제약

- **영문 검색 노출**: 영문은 같은 주소에서 전환하는 방식이라 검색엔진에는 주로 한국어로 노출됩니다.
  해외 검색 유입을 본격적으로 노리게 되면 `/en/` 영문 전용 페이지를 따로 만드는 것을 권장합니다.
- **게시글 검색 노출**: 게시판 본문은 스크립트로 그려집니다. 검색 노출이 중요한 글은 블로그 등 외부 채널에도 함께 게시하십시오.
- **전송 한도**: 구글 시트 방식은 알림 메일 하루 100명(개인 구글 계정), Web3Forms 무료는 월 250건입니다. [자세히](docs/이메일-접수-설정.md)
- **저장소 공개 범위**: 이 저장소는 현재 **공개(public)** 입니다. `docs/` 의 내부 검토 문서도 저장소에서는 누구나 볼 수 있습니다.
