# 주식회사 그린파스처 홈페이지

Green Pasture Co., Ltd. 공식 홈페이지 소스입니다. 나노 촉매 코팅 **V-ZERO**를 소개하고 견적 · 샘플 · 시공 상담 · 파트너 신청을 받습니다.

별도의 설치나 빌드 과정 없이 **HTML 파일을 그대로 열면 바로 동작**합니다.
메모장이나 VS Code 같은 편집기로 직접 수정하실 수 있습니다.

> 📋 오픈 전에 고객사에 받아야 할 자료와 확인할 내용은 **[docs/고객-확인사항.md](docs/고객-확인사항.md)** 에,
> 온라인 접수(데이터베이스 · 관리자 페이지) 설치 방법은 **[docs/SETUP.md](docs/SETUP.md)** 에 정리했습니다.

## 4. 자주 하는 수정 방법

### 연락처 · 주소 · 사업자등록번호 · SNS 바꾸기
`assets/js/site.js` 맨 위 **SITE** 부분만 고치면 헤더 · 푸터 · 모바일 메뉴에 **한 번에 반영**됩니다.

```js
const SITE = {
  tel: '010-3497-2524',
  email: 'ceo@greenpasture.co.kr',
  addressKo: '경기도 광주시 곤지암읍 벌열미길 39-14',
  bizNo: '',            // ← 사업자등록번호를 받으면 입력
  sns: {
    instagram: '',      // ← 주소를 넣으면 푸터에 아이콘이 나타납니다
    youtube: '', blog: '', facebook: '', linkedin: '', kakao: ''
  }
};
```

> 본문 곳곳(문의하기 카드, 오시는 길, CTA 영역)에도 전화번호 · 이메일이 직접 적혀 있습니다.
> 번호가 바뀌면 `010-3497-2524` 와 `01034972524` 로 저장소 전체를 검색해 함께 바꾸십시오.

### 메뉴 추가 / 삭제 / 이름 변경
같은 파일의 **NAV_ITEMS** 배열을 수정합니다. `children` 은 드롭다운 하위 메뉴입니다.

### 글 내용 수정 (한글 / 영문)
본문은 한국어와 영어가 나란히 들어 있습니다. 필요한 쪽만 고치면 됩니다.

```html
<span data-lang="ko">한국어 문장</span>
<span data-lang="en">English sentence</span>
```

### 공지 · 소식 글 올리기
`assets/data/posts.js` 의 `GP_POSTS` 배열 **맨 위**에 아래 한 덩어리를 복사해 붙이고 내용만 바꿉니다.
저장하면 게시판과 메인 화면 "공지 · 소식"에 자동으로 나타납니다.

```js
{
  id: 'new-post-2026-11',          // 영문 · 숫자 · - 만 사용, 다른 글과 겹치지 않게
  category: 'news',                // notice 공지사항 / news 회사 소식 / tech 기술·자료 / press 보도자료
  date: '2026-11-01',
  pinned: false,                   // true 면 목록 맨 위 고정
  title:   { ko: '제목', en: 'Title' },
  summary: { ko: '한 줄 요약', en: 'One-line summary' },
  body: {
    ko: `<p>본문 문단</p>`,
    en: `<p>Body paragraph</p>`
  }
},
```

글 주소는 `news.html?id=글id` 입니다. 최근 14일 이내 글에는 NEW 표시가 붙습니다.

### 사진 · 로고 교체
`assets/img/` 에 같은 이름으로 덮어쓰면 HTML을 고칠 필요가 없습니다.

| 파일 | 쓰이는 곳 | 권장 |
|---|---|---|
| `logo-gp.png` | 헤더 · 푸터 로고 (GP 심볼) | 투명 배경 PNG, 가로 300px 이상 |
| `vzero-emblem.jpg` | 메인 첫 화면 · 회사 소개 | 어두운 배경 그대로 사용 (화면에서 배경이 자연스럽게 녹아듭니다) |
| `prod-*.jpg` | 제품 3종 | 흰 배경 제품 사진, 가로 1000px 이상 |
| `app-*.jpg` | 7대 산업 카드 | 가로 900px 이상 |
| `leader-*.jpg` | 경영진 사진 | 정사각형, 800px 이상 |
| `og-image.jpg` | 카카오톡 · 페이스북 공유 미리보기 | 1200 × 630 |
| `favicon-*.png`, `apple-touch-icon.png` | 브라우저 탭 · 홈 화면 아이콘 | 정사각형 |

> 현재 이미지는 고객사가 보내 준 **V-ZERO 리플릿(인쇄용 PDF)에서 잘라낸 것**입니다.
> 해상도가 충분하지 않은 것이 있으므로 원본 파일을 받으면 교체하십시오.

### 색상 바꾸기
`assets/css/style.css` 맨 위 `:root { ... }` 안의 색상 값만 바꾸면 사이트 전체 톤이 바뀝니다.

## 5. 검토 모드 — "확인이 필요한 곳" 한눈에 보기

주소 뒤에 **`?review`** 를 붙여 열면 (예: `index.html?review`)
고객 확인이 필요한 부분이 **노란 점선**으로 표시되고, 왼쪽 아래에 몇 개인지와 각 항목의 메모가 나옵니다.
"다음 항목 보기"를 누르면 차례로 이동합니다. 끄려면 `?review=0` 을 붙이거나 "검토 모드 끄기"를 누르십시오.

HTML 에서는 `data-tbd="메모"` 가 붙은 곳이 해당 항목입니다.

> ⚠️ **오픈 전에 반드시** 모든 `data-tbd` 를 해결하고 속성을 지우십시오.
> 메모는 화면에는 안 보여도 페이지 소스에는 남기 때문에, 누구나 "소스 보기"로 읽을 수 있습니다.
> `grep -rn "data-tbd" --include=*.html --include=*.js .` 로 남은 항목을 찾을 수 있습니다.

## 6. 문의 · 신청 접수 방식

| 단계 | 동작 |
|---|---|
| **지금 (연결 전)** | 양식을 제출하면 방문자의 **메일 앱이 열리고** 내용이 채워진 채 `ceo@greenpasture.co.kr` 로 보낼 준비가 됩니다. 메일 앱이 없는 방문자를 위해 "내용 복사" 버튼과 전화번호도 함께 안내합니다. |
| **연결 후** | `docs/SETUP.md` 대로 Supabase 를 설치하고 `assets/js/config.js` 에 주소 · 공개 키를 넣으면, 양식이 **데이터베이스에 바로 저장**되고 담당자에게 알림 메일이 갑니다. 접수 내역은 `admin.html` 에서 확인 · 상태 변경 · 메모 · 엑셀(CSV) 내려받기를 합니다. |

양식에는 자동 입력 프로그램을 걸러내는 보이지 않는 칸(허니팟)과 개인정보 수집 · 이용 동의가 들어 있습니다.
연결 후에는 반복 접수 제한과 (선택) Cloudflare Turnstile 캡차도 동작합니다.

## 7. 배포 및 도메인 연결

### 자동 배포
`main` 브랜치에 변경 사항이 올라가면 GitHub 가 1~2분 안에 홈페이지를 자동으로 갱신합니다.
설정은 `.github/workflows/deploy-pages.yml` 에 있으며, **홈페이지에 필요한 파일만** 올라갑니다
(`docs/`, `supabase/`, `README.md` 는 웹사이트에 올라가지 않습니다).

- 기본 주소 : `https://intoedu.github.io/greenpasture/`
- 연결할 주소 : `https://www.greenpasture.co.kr`

### `www.greenpasture.co.kr` 연결 순서
1. GitHub 저장소 **Settings → Pages → Custom domain** 에 `www.greenpasture.co.kr` 입력 후 저장
   (자동 배포 방식에서는 `CNAME` 파일이 아니라 이 설정 화면이 기준입니다)
2. 도메인 등록 업체(가비아 · 후이즈 등) DNS 설정에 아래를 추가

   | 호스트 | 유형 | 값 |
   |---|---|---|
   | `www` | CNAME | `intoedu.github.io` |
   | `@` (루트) | A | `185.199.108.153` · `185.199.109.153` · `185.199.110.153` · `185.199.111.153` |

   값은 GitHub 공식 문서("Managing a custom domain for your GitHub Pages site")의 최신 값을 한 번 더 확인하십시오.
3. DNS 가 반영되면(수 분~최대 48시간) 같은 화면에서 **Enforce HTTPS** 를 켭니다.
4. 기존에 연결된 홈페이지 · 메일(MX 레코드)이 있다면 **메일 레코드는 건드리지 마십시오.** `ceo@greenpasture.co.kr` 수신이 끊길 수 있습니다.
5. `www.vzero.co.kr` 도 같은 사이트로 보내려면, 등록 업체의 "도메인 포워딩"으로 `https://www.greenpasture.co.kr/business.html` 로 넘기는 방법이 가장 간단합니다.

### 검색엔진 등록 (오픈 직후)
1. **네이버 서치어드바이저** (searchadvisor.naver.com) → 사이트 등록 → HTML 태그 방식의 확인 코드를
   `index.html` 의 `naver-site-verification` 주석 자리에 넣고 배포 → 소유 확인 → `sitemap.xml` 제출
2. **구글 서치 콘솔** 도 같은 방식 (`google-site-verification`)
3. `sitemap.xml` 의 `lastmod` 날짜는 큰 개편 때마다 갱신하십시오.

## 8. 외부에서 불러오는 것

| 항목 | 설명 | 빼도 되는지 |
|---|---|---|
| 글꼴 (Pretendard) | 무료 공개 글꼴을 jsDelivr CDN 으로 연결 | 빼도 됨. 애플 SD 고딕 · 맑은 고딕으로 자동 대체 |
| 지도 | 구글 지도 임베드 + 네이버 · 카카오 지도 바로가기 버튼 | iframe 주소만 바꾸면 교체 가능 |
| supabase-js | 관리자 화면(`admin.html`)에서만 사용 | 온라인 접수를 쓰지 않으면 불필요 |
| Cloudflare Turnstile | 캡차. `config.js` 에 키를 넣을 때만 불러옴 | 선택 |

방문 분석 도구(구글 애널리틱스 등)와 쿠키는 쓰지 않습니다. 언어 선택 값만 방문자 브라우저에 저장합니다.

## 9. 알아두실 제약

- **영문 검색 노출**: 영문은 같은 주소에서 전환하는 방식이라 검색엔진에는 주로 한국어로 노출됩니다.
  해외 검색 유입을 본격적으로 노리게 되면 `/en/` 영문 전용 페이지를 따로 만드는 것을 권장합니다.
- **게시글 검색 노출**: 게시판 본문은 스크립트로 그려집니다. 구글은 대체로 읽지만 네이버는 읽지 못할 수 있으므로,
  검색 노출이 중요한 글은 블로그 등 외부 채널에도 함께 게시하십시오.
- **저장소 공개 범위**: 이 저장소는 현재 **공개(public)** 입니다. `docs/` 의 내부 검토 문서도 누구나 볼 수 있습니다.
